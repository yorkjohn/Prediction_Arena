# Prediction Arena · 14 号现场运行说明

ICDM Youth 现场二元预测互动 Demo 的**本地版**实现。对应方案 `../Prediction_Arena_Plan.md`。

**不需要 ICP 备案、不需要小程序账号、不需要服务器、不需要外网、不需要审核。**
笔记本起一个 Flask 服务，手机连同一个 Wi-Fi，扫码即玩。

> **题库：100 道正式题 + 3 道练手，全部为真实市场数据。**
> 五类各 **20 道**（已达方案 §3.2 要求），YES 48 / NO 52。
> 来源：Polymarket 6 / Manifold 77 / Kalshi 5 / Betfair 交易所（football-data.co.uk）12。
> 每道都带来源链接、快照口径与结算结果；**唯一待办：展示许可仍需人工核实**（第 5 节）。

## 1. 与方案的偏离

| 项 | 原方案 | 本版 | 原因 |
|---|---|---|---|
| 手机端 | 微信原生小程序 | H5 网页 + 二维码 | 正式上架要 ICP 备案（最长 20 工作日）；体验版只有 15–30 个体验成员名额 |
| 后端 | Flask + SQLite + Linux/HTTPS | Flask + SQLite，笔记本本地 | 不买服务器、不配域名；现场不依赖外网 |
| 身份 | `wx.login` + 微信头像昵称 | 自填昵称 + 彩色首字母头像 | H5 拿不到微信身份 |
| 题库规模 | 每类 20 道 / 共 100+ 道 | **每类 20 道 / 共 100 道真实市场题** | 两轮采集 + 人工筛选后达标 |
| 数据源 | Polymarket / Betfair / Manifold / Metaculus | Polymarket / Manifold / Kalshi / **Betfair 交易所赔率（经 football-data.co.uk 免费 CSV）** | Betfair 官方历史数据要购买且限制再分发；免费 CSV 路子落地了方案 §5.3 |
| 参考概率 | 事件前真实市场快照 | **就是真实快照**，无编造数值 | 数值可回溯到具体市场或 CSV 行 |

**保留**：练手 3 题不计分、独立随机抽 5 题、随机类别、提交锁定、完成 5 题统一揭晓、Brier Score / Hit Rate、统一排行榜、匿名看板（3 秒轮询）、中英切换、答案不下发前端（方案 §8.5）。

## 3. 现场四步 · 手机到底怎么连

**第 0 步（提前，一次性）**
```bash
pip install -r requirements.txt
python smoke_test.py             # 应输出 "33 checks passed"
python validate_questions.py    # 应输出 Structure OK, 0 warnings
```

**第 1 步：连网** — 笔记本连会场 Wi-Fi，或**自己开热点让笔记本和观众手机都连上来**。
> ⚠️ 会场 Wi-Fi 常开 AP / 客户端隔离，手机会访问不到笔记本。**这是现场最常见的故障**，改用笔记本热点最稳。

**第 2 步：起服务**
```bash
python app.py
```
终端打印 `Phone URL: http://192.168.31.222:5000/`（IP 随网络变化），**不要关这个窗口**。

**第 3 步：手机打开**

| 方式 | 怎么做 |
|---|---|
| ✅ 最稳 | 手机**浏览器**（Safari / Chrome）直接输入 `http://<IP>:5000/` |
| ✅ 现场最方便 | `python make_qrcode.py` 生成 `qrcode.png`，投屏或打印让观众扫 |
| ⚠️ 微信扫码 | 微信「扫一扫」若打不开内网 HTTP 地址，点右上角「…」→「在浏览器打开」 |

**链路自检**：手机打开 `http://<IP>:5000/api/health`，看到 `{"ok":true,"real_questions":100,...}` 就通了。组织者在笔记本开 `http://127.0.0.1:5000/dashboard`。

| 现象 | 原因 / 处理 |
|---|---|
| 一直转圈打不开 | 会场 WiFi AP 隔离 → 笔记本开热点，手机改连热点 |
| 换个场地不能用 | IP 变了 → 重跑 `python make_qrcode.py` 或看终端新 URL |
| 微信扫码没反应 | 改用手机浏览器手动输入 |
| 页面能开但提交报错 | 服务窗口被关，或手机切到别的 WiFi / 移动数据 |
| 提示无法访问 | 确认手机和笔记本在同一网段 |

**现场不需要外网**：只要笔记本和手机之间局域网通，飞行模式 + 只开 WiFi 也能玩。

**第 4 步：留档** — 看板「导出成绩 CSV」下载全部提交明细；结束时复制 `arena.db`。

## 5. 数据源实测结论与待办

| 平台 | 状态 | 说明 |
|---|---|---|
| **Polymarket** | ✅ 6 题 | Gamma API + CLOB `prices-history`；**必须带 `interval` 参数**，否则静默返回空数组 |
| **Manifold** | ✅ 77 题 | `/v0/bets` 参数是 **`contractId`**（不是 `marketId`），用 `probAfter` 重建结算前概率。两轮采集，宽关键词搜索 |
| **Kalshi** | ✅ 5 题 | `api.elections.kalshi.com/trade-api/v2`；体育市场开到赛后，用官方 `previous_price_dollars`（前一交易日收盘） |
| **Betfair Exchange（football-data.co.uk）** | ✅ 12 题 | 免费 CSV `mmz4281/2425/E0.csv`，380 场英超。`BFEH/BFED/BFEA` 是交易所赔率（`BFH` 组是普通博彩，不用）。按 §5.3 归一化，赔率为赛前 pre-closing |
| **Metaculus** | ⏸ 待权限 | 默认档取不到题干与历史社区曲线；已申请 Bot Benchmarking / Unrestricted |
| **IEM** | ❌ | 历史数据页几乎全是选举（题材排除）；电影票房市场页无价格与结算数值 |

### 采集与筛选链路

1. 首轮 143 道候选 + 二次补采 93 道（去重后 **227 道**），另有 349 道英超可用比赛
2. 严格排除政治 / 选举 / 战争 / 监管 / 诉讼 / 八卦 / 个人化市场；概率保留 0.10–0.90
3. 按熟悉度、题干清晰度、概率梯度（0.22–0.82 分层）、YES/NO 平衡人工筛出 100 道，五类各 20 道
4. `build_question_bank.py` 只写中英文文案，**概率、结果、时间戳、链接全部从候选池/CSV 读取**，脚本里没有手写数字

### 仍需人工完成

- **API / 展示许可核实（方案 §10.3）**：`license_status` 多为 `NEEDS_MANUAL_REVIEW`。football-data.co.uk 官网明确 "My data is free"，但**没有正式许可条款**说明再分发/署名，建议现场材料注明来源；其余三家也需确认
- **四平台说明**：方案 §5 列四家，实际落地四家但构成不同（含 Kalshi、不含 Metaculus），前台若列平台名称须如实说明
- **口径差异**：Polymarket/Manifold 是「结算前 ≥1h 最后成交价」，Kalshi 是「前一交易日收盘」，足球是「赛前 pre-closing 赔率归一化」
- **题目熟悉度复核**：请 10–15 名相近受众试读，超过约三分之一已知结果的题优先淘汰（审核表已留空列）

练手 3 题是教学示例，`benchmark_probability` 为 `null`，不参与任何统计，也不展示参考概率。

## 6. 安全与隐私

- `outcome` / `benchmark_probability` **绝不出现在题目下发接口**；`seed/` 不在 Flask 静态目录内，URL 访问返回 404
- 导出接口仅笔记本本机可访问，导出内容不含 `client_id` / OpenID / 手机号
- 不收集手机号、身份证、钱包地址；只有浏览器本地随机 ID + 自填昵称
- 看板只返回匿名聚合数据，无单人预测或昵称
- 无真实交易入口、无外部平台登录，适合有未成年参与者的场合

## 7. 小程序正式版手续（不占 14 号关键路径）

**14 号现场只用本地 H5，下面这套手续完全不影响现场。**

### 排期（从 2026-11-06 财务打款算起）

| 环节 | 时长 | 备注 |
|---|---|---|
| 认证费打款 → 微信认证审核 | **1–5 工作日** | 官方现行口径，以通知中心派单消息起算；认证联系人保持电话畅通 |
| 认证通过 → 提交 ICP 备案 | — | **官方硬前置**：非个人主体必须完成微信认证；另需基本信息填完、至少一个类目审核通过、小程序负责人人脸核身与附件齐备，备案入口才可用 |
| 备案平台初审 | 1–2 工作日 | 站内信 / 模板消息 |
| 工信部 12381 短信核验 | **24 小时内** | 逾期自动驳回、需全部重提 |
| 通管局审核 | 1–20 工作日 | 各省不同 |
| 服务类目 / 隐私指引 / 提审 | 视审核 | 教育、医疗、出版等类目需前置审批资质 |

最坏约 12 月上旬拿到备案号。**备案号下来前不能提交代码审核或发布**（errcode 86369）。
认证失败不退费；名称审核失败后不能改名称，只能重新付费提交认证 —— 材料一次过很重要。

### 今晚就能备齐的材料

- 营业执照官方接受**三选一**格式：彩色原件照片 / 原件扫描件 / **加盖公章的复印件**。能交彩色原件扫描件就不需要盖章
- 「务必加盖公司公章」指的是在**复印件**上盖，**不是**往营业执照原件上盖；原件不要涂画、不要加章
- 走复印件路径：A4 复印或彩打 → 空白处盖**公司公章**（红色鲜章，非财务章 / 合同章 / 部门章，别压住注册号、二维码、登记机关章）→ 建议加注「仅供微信小程序认证使用」→ 彩色扫描上传
- 已三证合一的主体**不用再找《组织机构代码证》**，直接上传最新营业执照即可
- 别和《微信公众平台认证公函》搞混：那是另一份文件，盖章 + 签字在公函上
- 法人 / 主体负责人 / 小程序负责人身份证，**证件有效期 > 1 个月**、边角齐全
- **主体负责人与小程序负责人用两个不同手机号**，初审期间保持畅通
- 小程序负责人人脸核验照片：白或浅色纯背景、无杂物他人、不戴帽子耳机口罩、不闭眼
- 主体负责人 ≠ 法人时，部分省要授权书，先查本省管局要求
- 材料拿不准可直接打第三方审核公司热线（官方认证指引列了 4 家），比猜快

### 三个最容易翻车的点

1. **主体信息一字不差**：与微信认证主体完全一致，建议截图留档照抄。
2. **24 小时短信核验**：12381 短信后在 `beian.miit.gov.cn` 核验，周末也要盯；超时整个备案重提。
3. **服务类目慎选**：教育（尤其学科教育）、医疗、新闻、出版、直播需前置审批资质；本项目是预测科普游戏，优先选不需资质的类目。

### 名称审核（2026-11-06 收到「可能涉及企业商标」提示）

原名疑似命中商标库，审核要求补《商标注册证》或商标授权文件。**没有商标就直接改名**，比补材料快得多。

官方命名禁区（`reject.html` 1.1 / 1.2）：不得含不属于本主体的品牌或商标、不得含「国家级 / 最高级」等商业化绝对化用语；名称与简介、实际功能必须一致；**必须是两个词以上的组合、具有识别性**，不能用纯通用词或单词汇；简介里要能找到名称或拆出来的词。ICP 备案另要求名称与主体性质、工商经营范围相关联。

推荐提交名：**概率校准实验室**
备选（查重被占用时依次换）：`概率思维实验室` / `概率校准课堂` / `〔公司字号〕概率科普` —— 最后一种带自有字号，与主体关联最强，通过率最高。

配套简介（与名称一起改；官方要求简介中能找到名称或拆出的词，长度一般 4–120 字，一个月内修改次数有限，一次填好）：

**主推版（后台「功能介绍」直接粘贴，约 88 字）**
> 面向学术会议观众的二元概率科普互动实验：对真实历史事件给出 YES 概率，与预测市场赛前快照对照，用 Brier Score 检验判断把握，讲解概率校准与 Hit Rate。纯科普，不涉及交易、下注或资金。

**精简版（约 60 字）**
> 二元概率预测科普互动实验：给历史事件一个 YES 概率，与赛前市场快照对照，用 Brier Score 检验把握，讲解概率校准。不涉及交易。

**审核备注 / 补充说明（提交审核时填，帮助审核理解经营范围）**
> 本小程序用于学术会议现场的概率预测科普互动：观众选择题材后系统随机抽取 5 道已结算历史事件题，提交 0–100% 的 YES 概率，完成后对照预测市场赛前快照，展示 Brier Score、Hit Rate、个人排行榜与匿名群体统计，并讲解概率校准。支持中英文切换。全部题目与概率来自公开历史数据的教学展示，不提供真实交易、下注、支付或资金功能，不收集手机号等敏感信息，不面向未成年人做商业化运营。

首页欢迎语（产品内展示）：「预测不是猜 YES 或 NO，而是说出你有多大把握。」

注意：简介里**不要出现具体第三方平台名**（Polymarket / Betfair 等），避免被判为「包含不属于本主体的品牌」；也不要出现「官方 / 最 / 第一 / 国家级」等词。名称「概率校准实验室」共 7 个汉字 = 14 字符，在官方 4–30 字符范围内。

操作：**别等驳回**，立即联系第三方审核公司（4 家热线见官方认证指引第 14 节）申请修改认证名称 / 退回重填；审核中 30 天内有 3 次重填机会。**名称审核一旦失败，不能改名称，只能重新付费提交认证且费用不退**。改名时一并考虑 ICP 备案的「名称与经营范围关联」要求，别取太花哨的名字导致认证过了备案又卡。

### 服务类目怎么选

**按「实际提供的服务」选，不按题目题材选**：题库里有体育 / 电竞 / 科技题，但服务本身是概率科普互动工具，别因此选「体育」「游戏」「在线课程」。

绝对避开：

- **游戏类目**：官方小游戏类目规则「一级类目不支持修改，选择错误只能重新注册」，且需版号等资质；微信开放社区有真实案例——误勾选游戏类目后无法改回「工具-休闲娱乐」，因办不了版号连支付都受限。本产品有答题和排行榜，看着像游戏，但**绝不能选游戏**。
- 需前置资质的类目：`教育服务 > 学历教育 / 培训机构 / 非学科类培训 / 在线视频课程 / 教育平台`（办学许可证、增值电信业务经营许可证）、新闻 / 出版 / 医疗 / 金融 / 直播 / 社交（增值电信许可）。我们一项都没有。

推荐：后台「设置 → 基本设置 → 服务类目」里，优先找**「工具」大类下信息查询 / 效率 / 数据统计类、资质要求为「/」或仅需营业执照**的类目；次选「IT科技 / 商业服务」中与数据展示、会议活动相关的无资质类目。**只选 1 个最贴合的主类目**，别堆不相关类目凑数。

配套要求（官方 `reject.html` 2.1 / 3.1.2 / 1.2.3）：类目对应的页面核心内容必须与类目一致，首页 2 次点击内可到达；服务标签不能超出服务范围。另 3.2.4 禁止「测试类内容」（算命 / 抽签 / 星座），页面文案用「练手 / 实战 / 预测 / 评分」，别写「测一测」。

官方类目表会变且自注「以提交时所要求的材料为准」，最终以后台实际可选项为准。

### 备案入口为什么点不了

备案是整条链的**最后一步**，不是独立入口。官方开放平台「申请小程序备案」接口文档列的前置条件：

1. 小程序名称、图标、描述等基本信息已填写完成
2. **至少存在一个审核通过的类目**
3. **非个人类型小程序必须完成微信认证**
4. 小程序负责人人脸核身完成、所需附件材料齐备

接入指南另明确：「选择通过微信认证验证主体身份的用户，需先完成微信认证后，才可以补充小程序名称信息、上传头像、填写介绍并选择服务范围。」

所以正确顺序是：`认证通过 → 名称/头像/简介/类目（类目需审核通过）→ 人脸核身 + 附件 → 备案`。认证还在审核中时，首页引导页的备案卡片置灰是正常状态，不是入口坏了。

入口位置：未上架小程序在后台首页点【去备案】，或「设置 → 基本设置 → 小程序备案 → 前往备案」。若仍不可点，排查：登录账号是否**管理员**（运营者权限不足）、主体备案数量是否达上限（企业 50 / 个人 5）、换 Chrome 清缓存重新扫码登录；第三方平台代开发的小程序需走服务商代备案流程。

体验成员上限（15 / 30 / 90 人）与 ICP 备案是两回事：前者只影响内测人数，后者才卡正式上架。

小程序工程骨架可与手续并行开发，不依赖账号；本版 H5 的游戏逻辑与 100 道题库结构可直接复用。
